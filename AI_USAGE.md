## Tasks AI assisted with

- Writing the application code (models, schemas, services, routers, authentication)

## Prompt used
A single detailed "master prompt" describing the full assignment (stack, models, endpoints, business rules, validation, JWT, pagination, tests, docs, Git). It asked the AI to build the whole project and not to claim anything it had not verified.

- **Not verified in the AI's sandbox** (no internet, no PostgreSQL there): installing dependencies, connecting to PostgreSQL, starting the server, running pytest, viewing Swagger.
